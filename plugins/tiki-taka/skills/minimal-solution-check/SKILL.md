# Minimal Solution Check

Before implementing, first answer:
1. Can you use the stdlib/built-in of this language/framework, without a new dependency?
2. If you need a dependency, is it truly needed now (not "might be useful later")?
3. Is a native/platform capability available before building your own abstraction?
4. Is this solution still the simplest that stays correct — not the smartest/cleverest?

If any answer is "no", choose the more minimal option first before continuing to code.
